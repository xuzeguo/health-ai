## 检查边界与后续

这是本地待提交内容与 Git 历史检查，不是远端审计。准备时 GitHub 访问受环境限制：代理不可达，直连域名无法解析；远端已有内容、可见性与推送结果须在连通后确认。不使用 force push 覆盖远端。

未来新增文件、修改凭证或变更日志时需重新检查。不要提交真实 `.env`、聊天库或用户导出数据；不要使用 `git add -f` 绕过忽略规则。若凭证曾在其他仓库/提交中公开，应在供应商侧撤销并重建，删除文件本身不能撤销泄漏。
