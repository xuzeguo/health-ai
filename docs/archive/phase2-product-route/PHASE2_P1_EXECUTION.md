# F02-P1 执行规格

日期：2026-11-17。范围：二期基础契约、持久化元数据、共享任务占位和模型端口骨架；不实现报告上传、正式工具或 RAG 产品流程。

## 测试条件

| ID | 条件与动作 | 预期 |
| --- | --- | --- |
| P1-01 | 空库启动、旧一期库重开、重复启动 | 一期表与消息保持，迁移元数据可重复校验 |
| P1-02 | 缺少关键列或迁移校验不一致 | 启动失败且不留下半个迁移 |
| P1-03 | 同会话同时 reserve 两种任务、不同会话并发 | 同会话仅首个成功，不同会话均成功 |
| P1-04 | 旧 task 迟到 release，新 task 已占用 | 新占位仍保持，关闭后全部释放 |
| P1-05 | text/tool/截断/空结果端口事件 | text 与 tool 正常终态可区分，非法终态拒绝 |
| P1-06 | v2 帧版本、序号、工作流/消息 ID错误 | 解码器拒绝错误帧，v1事件不变 |
| P1-07 | 相同/不同 requestId 重复请求 | 相同摘要可对账，不同摘要冲突，不自动重发 |
| P1-08 | 增量/终态提交失败、启动恢复 running | 未提交内容不发布，终态不倒退，running 标记 interrupted |
| P1-09 | 关闭时新任务、非合作 iterator、敏感标记 | 新任务拒绝，有界收尾，日志/事件不含 Key、正文、reasoning |

## 放行

先执行新增 P1 契约测试，再执行 `pnpm test`、`pnpm typecheck`、`pnpm build`。P1 未完成的上传、工具、索引和组合界面不纳入本阶段；完成前不得进入 P2。
